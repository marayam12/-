# RenexaMC – تطبيق أندرويد (Kotlin + WebView)

## ✅ تحديث: صفحة الأوفلاين انصلحت
اللي كان يصير بالسكرين شوت (عناصر بلا أي تنسيق) سببه إن `assets/index.html` القديمة كانت
نفس نسخة الموقع الحيّ اللي تعتمد بالكامل على Tailwind CDN وFont Awesome وGoogle Fonts
وthree.js وskinview3d وqrcodejs وtwemoji — كل هذي روابط خارجية، فأوفلاين ما راح تشتغل
أبدًا مهما سويت، لأنها مو ملفات داخل مشروعك.

لكن حتى لو انبنت محليًا، الصفحة القديمة كانت غير مفيدة أوفلاين أصلًا: تسجيل الدخول،
الكوينز، السوق، الشات، القوائم — كل هذا يعتمد على Firebase حيّ، ولن يشتغل بدون نت
بغض النظر عن التنسيق.

فبدل ما نحاول نجهز نسخة كاملة من موقع بـ 6500 سطر ومكتبات خارجية بس عشان تظهر بشكل
جميل بينما لا شيء فيها يشتغل، القديمة (`index.full.html.bak`) محفوظة كمرجع، واستبدلتها
بصفحة أوفلاين حقيقية وبسيطة: بدون أي رابط خارجي (كل شي inline)، فيها اللوغو، ورسالة
واضحة إنك محتاج نت، وزر "إعادة المحاولة". ثنائية اللغة تلقائيًا (عربي/إنجليزي حسب لغة
الجهاز). ما راح تنكسر أبدًا لأنها ما تعتمد على أي شي خارجي.

أيضًا ركّبت أيقونة التطبيق (adaptive icon) من صورة الـ R/الفأس اللي بعتها.



## اللي سويته
مشروع Android Studio (Gradle) كامل، بواجهة WebView تفتح موقعك:
- **لو فيه إنترنت** → يفتح الموقع الحيّ (`remoteUrl` في MainActivity.kt).
- **لو ما فيه إنترنت** → يفتح تلقائيًا نسخة `index.html` المخزّنة جوّا التطبيق نفسه (`app/src/main/assets/index.html`)، بدل ما يطلع خطأ.
- إذا فشل تحميل الصفحة الحيّة لأي سبب أثناء التصفح، يرجع تلقائيًا لنفس النسخة المحلية بدل صفحة الخطأ.

## ⚠️ مهم جدًا قبل ما تبني — سبب اللي صار بالسكرين شوت
اللي شفته بصورتك (العناصر فوق بعض بدون تنسيق) صار لأن index.html يجيب كل شي من الإنترنت:
Tailwind CDN، Google Fonts، Font Awesome، three.js، skinview3d، qrcodejs، twemoji.

حتى لو فتحت الملف من داخل التطبيق (offline)، هالمكتبات ما راح تشتغل بدون نت، لأنها روابط خارجية — مو ملفات داخل مشروعك. يعني "يشتغل بدون نت 100%" يحتاج خطوة إضافية:

1. نزّل هالملفات فعليًا (tailwind css مبني مسبقًا، خط Tajawal، font-awesome، three.min.js، skinview3d bundle، qrcode.min.js) وحطها في `app/src/main/assets/libs/`.
2. بدّل الروابط بـ index.html من `https://cdn...` إلى مسارات محلية زي `libs/tailwind.css`.

بدون هالخطوة، التطبيق راح يفتح offline لكن بدون تنسيق (نفس اللي صار بالصورة). قلي إذا تبيني أسوي هالخطوة كاملة وأجهزها لك.

## كيف تبنيه من Codespaces
```bash
# داخل مجلد المشروع
gradle wrapper          # أول مرة بس، يولّد gradlew
./gradlew assembleDebug
```
الـ APK يطلع في: `app/build/outputs/apk/debug/app-debug.apk`

لازم يكون عندك Android SDK داخل الـ Codespace (أضف `.devcontainer` فيه صورة تدعم Android، أو ثبّت `sdkmanager` يدويًا).

## قبل ما تبني، غيّر هذا:
في `MainActivity.kt`، بدّل:
```kotlin
private val remoteUrl = "https://example.com/index.html" // <-- CHANGE ME
```
لرابط موقعك الحقيقي المستضاف (GitHub Pages أو غيره).

## ملاحظة عن server.js
ملف `server.js` (Votifier relay) سيرفر Node منفصل لازم يشتغل على استضافة توفر Node.js (Render/Railway/VPS) — ما ينحط جوا تطبيق الأندرويد، والتطبيق يكلمه عن طريق fetch زي ما هو مبرمج بالموقع.
